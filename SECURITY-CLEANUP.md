# Приватные настройки и данные

- Секреты в отслеживаемых конфигурациях очищены. Перед запуском заполните приватную копию конфигурации окружения и не добавляйте её в Git.
- Пустые строки являются отсутствующими настройками. Приложению потребуются действующие реквизиты; эта правка не восстанавливает доступ автоматически.
- Для ASP.NET Core переопределите существующие параметры штатным механизмом конфигурации. JSON сам не подставляет переменные окружения.
- Для .NET Framework используйте приватную конфигурацию установленного приложения. Очищены также исходные .settings и сгенерированные значения.
- Найденные токены и пароли нужно отозвать или заменить. Действительность секретов внешними запросами не проверялась.
- История Git сохраняет прежние значения и удалённые файлы. Слияние этого изменения не очищает историю.

Параметры запуска C#:

- SERVICE_PASSWORD
- SERVICE_USERNAME
